Syntax for my own invented language Lan:

<<<<<<<<<<<<<<<<< TYPES >>>>>>>>>>>>>>>>>
- Bool: True, False
- Char: '<char>'
- String: "<string>"
- Int: XX
- Float: XX.XXX
- List: [XX,XX,...] (allows for elements of different types)
- Func: <func_name>

(Any denotes any type)
(Ord = {Char, String, Int, Float})
(Num = {Int, Float})
(Concat = {String, List})

<<<<<<<<<<<<<<<<< PRIMITIVES >>>>>>>>>>>>>>>>>
A. Primitive Operators: (infix)
    Precedence 0:
    (||) :: Bool -> Bool -> Bool

    Precedence 1:
    (&&) :: Bool -> Bool -> Bool

    Precedence 2:
    (==) :: Any a => a -> a -> Bool
    (!=) :: Any a => a -> a -> Bool
    (<) :: Ord a => a -> a -> Bool
    (>) :: Ord a => a -> a -> Bool
    (<=) :: Ord a => a -> a -> Bool
    (>=) :: Ord a => a -> a -> Bool

    Precedence 3:
    (+) :: Num a => a -> a -> a
    (-) :: Num a => a -> a -> a

    Precedence 4:
    (*) :: Num a => a -> a -> a
    (/) :: Num a => a -> a -> a
    (//) :: Int -> Int -> Int
    (%) :: Int -> Int -> Int

B. Primitive Functions: (applied using Function Application syntax)
    head :: Any a => List -> a 
    tail :: List -> List
    concat :: Concat a => a -> a -> a
    get :: Any a => List -> Int -> a

<<<<<<<<<<<<<<<<< POSSIBLE ENTITIES OF CODE >>>>>>>>>>>>>>>>>

1. Declaring Variables: (start with "var")
    var <var_name> : <type> = <value>

    Variable names:
    - starts with a letter
    - followed by letters / digits / '_'

2. Setting Variables: (start with "set")
    set <var_name> = <value>

3. Defining Functions: (start with "def")
    def <func_name> (<param1> : <type1> , ...) : <return_type> {
        <func_body>
    }

    Function names:
    - starts with a letter
    - followed by letters / digits / '_'

4. Conditionals: (start with "if")
    if ( <condition> )
    then { <then_body> }
    else { <else_body> }

5. For-loops: (start with "for")
    for ( <var_name> in range (<start>, <end>) ) {
        <loop_body>
    }
    for ( <var_name> in <list> ) {
        <loop_body>
    }

6. While-loops: (start with "while")
    while ( <cond> ) {
        <loop_body>
    }

7. Expression:
    Defined by Exprs below

<<<<<<<<<<<<<<<<< EXPRESSIONS >>>>>>>>>>>>>>>>>
1. Atoms:
= raw values of type Any | Variable reference ie <var_name> | Function Application ie <func_name> (<arg1>, ...) | (<Expr>)

2. Factors:
= <Atom> | <Atom> + [(<Prec4 Op>, <Atom>)]

3. Terms:
= <Factor> | <Factor> + [(<Prec3 Op>, <Factor>)]

4. Comps:
= <Term> | <Term> + [(<Prec2 Op>, <Term>)]

5. AndExprs:
= <Comp> | <Comp> + [(<Prec1 Op, <Comp>)]

6. Exprs:
= <AndExpr> | <AndExpr> + [(<Prec0 Op>, <AndExpr>)]

Note:
Conditions = Exprs that evaluate to a Boolean
Block = 1 entity of code
    - Setting variables / Declaring variables / Expressions require a semicolon ';' or end-of-line character '\n' after itself
